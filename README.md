# Лабораторная работа 1. Консольный набор утилит

## Введение

В данной лабораторной работе реализован консольный набор утилит на Python.

Проект состоит из двух частей:

- калькулятора арифметических выражений;
- конвертера величин.

Программа запускается через командную строку.

Поддерживаются следующие команды:

```shell

python -m toolkit calc "EXPRESSION"

python -m toolkit convert VALUE --from UNIT --to UNIT

python -m toolkit --help
```

Калькулятор поддерживает целые и вещественные числа, операции `+`, `-`, `*`, `/`, унарные `+` и `-`, а также пробелы между токенами.

При вычислении соблюдается приоритет операций: умножение и деление выполняются раньше сложения и вычитания.

Для разбора арифметических выражений не используются `eval`, `exec`, `ast.literal_eval` и сторонние parser-библиотеки.

Конвертер поддерживает следующие единицы:

- длина: `mm`, `cm`, `m`, `km`;
- масса: `g`, `kg`;
- температура: `c`, `f`, `k`.

Регистр единиц не учитывается.

Конвертация между разными группами единиц запрещена. Температура ниже абсолютного нуля также считается ошибкой.

## Структура проекта

```shell
├── src/

│   └── toolkit/

│       ├── __init__.py

│       ├── __main__.py

│       ├── calculator.py

│       ├── cli.py

│       ├── constants.py

│       ├── converter.py

│       ├── errors.py

│       └── tokenizer.py

├── tests/

│   ├── __init__.py

│   ├── test_calculator.py

│   ├── test_cli.py

│   ├── test_converter.py

│   └── test_tokenizer.py

├── pyproject.toml

├── README.md

├── .gitignore

├── .pre-commit-config.yaml

└── uv.lock
```

В папке `src/toolkit` находится основная реализация программы.

`tokenizer.py` отвечает за разбиение арифметического выражения на токены.

`calculator.py` содержит вычислительное ядро калькулятора. В нём отдельно выполняются обработка унарных знаков, проверка последовательности токенов и вычисление выражения.

`converter.py` содержит логику преобразования единиц длины, массы и температуры.

`constants.py` содержит константы и таблицы коэффициентов, используемые конвертером.

`errors.py` содержит классы ошибок, используемых в калькуляторе и конвертере.

`cli.py` отвечает за разбор аргументов командной строки и вызывает соответствующую часть программы.

`__main__.py` является точкой входа при запуске команды `python -m toolkit`.

В папке `tests` находятся автоматические тесты для отдельных частей программы и `CLI`.

## Требования к коду

Переменные, функции и модули именуются в стиле `snake_case`.

Классы именуются в стиле `PascalCase`.

Названия переменных и функций должны быть понятными и отражать их назначение.

Функции имеют аннотации типов и docstring.

Вычислительная логика отделена от интерфейса командной строки. Функции калькулятора и конвертера не используют `input()` и `print()`.

Для проверки качества и типов кода используются `ruff` и `mypy`.

## Калькулятор

Формат команды:

``` shell
python -m toolkit calc "EXPRESSION"
```

Примеры:

``` shell
python -m toolkit calc "2+3\*4"
```

Результат:

``` shell
14.0
```

``` shell
python -m toolkit calc "10 / 4"
```

Результат:

``` shell
2.5
```

Поддерживается унарный знак:

``` shell
python -m toolkit calc "2 \* -3"
```

Результат:

``` shell
- 6.0
```

При ошибке программа выводит сообщение в stderr и завершается с кодом 2.

## Конвертер

Формат команды:

``` shell
python -m toolkit convert VALUE --from UNIT --to UNIT
```

Примеры:

``` shell
python -m toolkit convert 1000 --from mm --to m
```

Результат:

``` shell
1.0
```

``` shell
python -m toolkit convert 1.5 --from kg --to g
```

Результат:

``` shell
1500.0
```

``` shell
python -m toolkit convert 0 --from c --to f
```
Результат:

``` shell
32.0
```

Абсолютный ноль:

``` shell
- 273.15 c = 0 k
```

Значение ниже абсолютного нуля считается ошибкой.

## Ошибки

Программа обрабатывает следующие ситуации:

- пустое выражение;
- недопустимый символ;
- пропущенный операнд;
- пропущенный оператор;
- два оператора подряд;
- деление на ноль;
- неизвестная единица;
- несовместимые единицы;
- неверное числовое значение;
- температура ниже абсолютного нуля.

При успешном выполнении программа завершается с кодом `0`.

При пользовательской ошибке сообщение выводится в `stderr`, а код завершения программы равен `2`.

## Тесты

Для запуска всех тестов используется:

``` shell
python -m pytest
```

Для запуска только тестов калькулятора:

``` shell
python -m pytest tests/test\_calculator.py
```

Для запуска тестов конвертера:

``` shell
python -m pytest tests/test\_converter.py
```

Для запуска тестов CLI:

``` shell
python -m pytest tests/test\_cli.py
```

Тесты проверяют как успешные случаи, так и ошибки.

Вычислительное ядро тестируется напрямую, без запуска отдельного процесса. Для CLI используются отдельные тесты.

## Проверка кода

Для проверки стиля кода:

``` shell
ruff check .
```

Для проверки типов:

``` shell
mypy src tests
```

Для запуска всех проверок:

``` shell
python -m pytest
ruff check .
mypy src tests
pre-commit run --all-files
```
